# Sécurité et signalement

CADRE est un prototype non prêt pour un usage familial réel.

**Ne publiez pas de vulnérabilité exploitable avec données personnelles, secrets ou informations d'enfants dans une issue publique.** Contactez le responsable du dépôt via les moyens de contact privés de son profil GitHub, si disponibles. Si aucun canal privé n'est disponible, ouvrez une issue demandant un canal de signalement **sans divulguer les détails sensibles**.

Principes : consentement et transparence, minimisation des données, pas d'interception de contenus privés, pas de contournement des protections Android, pas de surveillance clandestine.

Les tests de restrictions fortes doivent se faire sur un appareil de test dédié, jamais sur le téléphone personnel d'un contributeur sans sauvegarde et consentement éclairé.
