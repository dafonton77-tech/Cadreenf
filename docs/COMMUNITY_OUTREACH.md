# Faire connaître CADRE — guide de diffusion

**État :** dépôt public et missions ouvertes ; **aucune candidature à un annuaire externe ni annonce sur un service tiers n'est considérée comme publiée** tant que le lien de publication n'est pas confirmé.

## Avant une soumission

- Licence du code : MIT (voir LICENSE et NOTICE.md).
- Descriptions FR/EN disponibles dans README et docs/PROJECT_OVERVIEW_EN.md.
- Issues accessibles et étiquetées `help wanted` / `good first issue`.
- Vérifier les critères exacts de chaque annuaire et les éventuelles exigences d'éligibilité.

## Canaux à examiner

1. [Up For Grabs](https://up-for-grabs.net/) : vérifier les instructions d'ajout d'un dépôt et les labels acceptés.
2. [For Good First Issue](https://forgoodfirstissue.github.com/) : vérifier l'éligibilité et la procédure de référencement.
3. [JeVeuxAider](https://www.jeveuxaider.gouv.fr/) : publication d'une mission associative après vérification du statut de la structure.
4. [Passerelles et Compétences](https://www.passerellesetcompetences.org/) : bénévolat de compétences pour association.
5. Communautés Android/open source : respecter les règles contre le recrutement ou l'autopromotion.

## Message court français

**Développeurs Android/Kotlin bénévoles recherchés — CADRE**

CADRE est un prototype open source de contrôle parental éducatif lié à la démarche Éducation Numérique France. Nous voulons associer des protections Android **techniquement réalistes** à l'autonomie progressive des enfants, sans espionner leurs conversations. Une base Kotlin compilable et un cahier des charges existent ; le contrôle parental complet **reste à développer**.

Nous recherchons des contributions bénévoles ciblées : audit Android, architecture parent/enfant, sécurité, tests et règles familiales. Licence du code : MIT. Premières missions : https://github.com/dafonton77-tech/Cadreenf/issues

## English message

**Volunteer Android/Kotlin contributors wanted — CADRE**

CADRE is an experimental MIT-licensed Android project for educational parental controls, combining technically feasible device protections with family dialogue and gradual autonomy. We have a buildable Kotlin prototype and specifications, **not a production-ready parental control app**. We welcome volunteers for Android feasibility, architecture, privacy/security, testing and family rules.

Start here: https://github.com/dafonton77-tech/Cadreenf/issues
